# АТМ — каталог YTO

Обновление по каталогу от 15.10.2026: десять моделей, единые данные, подробные характеристики, фильтры и сравнение.

**[Полный список изменений, источники и установка в WordPress](docs/CHANGES-YTO-2026.md)**

- Главная: `front-page.php`; исходная разметка — `index.html`.
- Шаблоны страниц: `catalog.php`, `product.php`.
- Данные моделей и пути фото: `catalog-data.js`.
- Общий вывод карточек: `catalog-ui.js`; взаимодействия: `pages.js`, `script.js`.
- Стили: `style.css`; локальные ресурсы: `assets`.

Фотографии пока заменены нейтральными заглушками. Прочитаны все 32 страницы PDF; добавлены филиалы и сервис. Таблицы всех десяти моделей проверены по доступным страницам 22–31.

Файлы `ekzomassage` относятся к другому проекту и не изменялись. Выставочная форма и её база также не затрагивались.

Финальное обновление: страницы `/branches/`, `/service/`, `/privacy/`, полная PDF-брошюра, UTM и события для рекламных целей. Инструкция установки и ограничения аналитики: [docs/CHANGES-YTO-2026.md](docs/CHANGES-YTO-2026.md).
