# ЭКЗОмассаж — сайт

Самостоятельный статический сайт. Исходные файлы `/workspace/stuba` не изменены.

Откройте `index.html` в браузере или запустите:

```sh
cd /workspace/ekzomassage
python3 -m http.server 8010
```

Для размещения на ekzomassage.kz загрузите `index.html`, `styles.css` и `app.js` в корневую папку сайта на хостинге. Домен и HTTPS настраиваются у хостинг-провайдера. Публикация на домен не выполнялась.

Запись работает через WhatsApp +7 (707) 922-20-80. Кнопка пробного сеанса подставляет услугу в сообщение. Серверная обработка заявок не требуется. Шрифт Manrope загружается из Google Fonts; без сети используется Arial.

Стоимость пробного сеанса, адрес и график перенесены из предоставленных материалов. Перед публикацией проверьте актуальность информации . Иллюстрация аппарата стилизованная, выполнена в SVG; это не фотография оборудования. Прикреплённые фотографии не включены в сайт: исходные файлы не были доступны в файловой системе.

Проверено в Chromium: адаптация 1440 и 390 px без горизонтальной прокрутки, мобильное меню, переходы по разделам, раскрытие FAQ, формирование WhatsApp-ссылок; ошибок JavaScript нет.
