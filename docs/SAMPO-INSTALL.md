# Sampo-Rosenlew — обновление для WordPress

Ветка `sampo` создана из актуальной `feat/yto-catalog-2026` (коммит `438e8e2`). Изменения сайта, внесённые пользователем в исходную ветку, сохранены.

## Что добавлено

- Отдельная главная Sampo, отдельный каталог и один шаблон товара для всех комбайнов. Раздел не загружает тракторный каталог, тракторные фильтры или характеристики.
- Четыре модели: Comia C12, Comia C20, SR C2, Comia C24. Для C24 характеристики не предоставлены: показаны запрос спецификации и консультация, без выдуманных цифр.
- C12: 300 л.с., бункер **от 7600 л**, 6 клавиш соломотряса; C20: 300 л.с., бункер **9000 л**, два ротора. SR C2 — отдельный **селекционный** комбайн, 130 л.с., бункер 1875 л, жатка 2,3 м. SR C2 не назван Comia.
- На телефонах — закреплённые кнопки звонка и WhatsApp.
- В карточках — собственные тексты Sampo, характеристики по документам, скачивание исходной технички, другие комбайны Sampo, WhatsApp и телефон. C24 не участвует в техническом сравнении, поскольку его параметры неизвестны.
- Каталог: поиск, фильтр назначения, сортировка мощности (неизвестная мощность — в конце), сравнение до трёх моделей. Без JavaScript модели и технические таблицы также видны.
- Блок предложения лизинга **именно Comia C12**: взнос от 10%, ставка от 5% годовых, срок до 7 лет. Информация предоставлена владельцем сайта; актуальность и индивидуальные условия подтверждает КазАгроФинанс. Это предложение не перенесено на C20, C2 или C24.
- На страницах YTO и Sampo — общие четыре категории после первого баннера/основного блока: Тракторы, Зерноуборочные комбайны, Почвообрабатывающая техника, Колеса. Активная категория красная. Иконки — отдельные заменяемые SVG.
- Для двух будущих направлений — общий шаблон страницы подбора с контактами, а не пустые или несуществующие ссылки. Каталоги Farmet/колёс не наполнены: нужны их данные.
- Формы Sampo подготавливают сообщение в WhatsApp с выбранной моделью. Посетитель отправляет его самостоятельно; сохранения заявок на сервере нет. UTM-метки сохраняются в пределах вкладки и добавляются в сообщение. События `atm_form_prepared` и `atm_contact_click` дополнены `brand: sampo` и известным кодом модели; имя и телефон в события не передаются. Рекламные пиксели и счётчики этим обновлением не устанавливаются.
- Исправлена загрузка Lucide в изменяемых страницах YTO: используется имеющийся локальный файл версии 0.468.0, инициализация защищена при отсутствии библиотеки.

## Загрузка файлов

Сделайте резервную копию темы. **Не удаляйте всю папку темы и не заменяйте WordPress целиком.** Новые и изменённые файлы копируются в папку активной темы, например `wp-content/themes/atm/`.

Новые файлы:

- `equipment-navigation.php`, `equipment.php`;
- `sampo.php`, `sampo-catalog.php`, `sampo-product.php`, `sampo-functions.php`;
- `sampo-data.json`, `sampo.js`;
- папки `assets/images/sampo/`, `assets/images/categories/`;
- документы `assets/docs/sampo-c12.docx`, `sampo-c20.docx`, `sampo-c2.pdf`.

Обновлённые файлы: `front-page.php`, `catalog.php`, `product.php`, `style.css`, `marketing.js`. Существующий `site-data.php`, `pages.js` и локальный `assets/vendor/lucide-0.468.0.min.js` также должны оставаться на месте. Они включены в архив обновления. `index.html` синхронизирован для исходников; в WordPress он не нужен и в архив для темы не включён.

Если вы редактировали CSS на хостинге после последней версии GitHub, объедините изменения или сохраните свои дополнения отдельно. Ваши фотографии YTO и `functions.php` не перезаписываются этим архивом.

## Какие страницы создать в WordPress

| Название | Ярлык (slug) | Выбрать шаблон |
|---|---|---|
| Sampo-Rosenlew | `sampo` | **Sampo — главная** |
| Каталог Sampo | `sampo-catalog` | **Sampo — каталог** |
| Комбайн Sampo | `sampo-product` | **Sampo — товар** |
| Подбор оборудования | `equipment` | **Категории техники — подбор** |

Все четыре страницы опубликуйте **без родительской страницы**, чтобы URL совпали со ссылками. Главной сайта остаётся YTO. Страницу товара создайте **одну**, не по странице для каждой модели.

Адреса:

- `/sampo/` — главная Sampo;
- `/sampo-catalog/` — только комбайны;
- `/sampo-product/?model=C12` (также `C20`, `C2`, `C24`);
- `/equipment/?type=tillage` и `/equipment/?type=wheels` — будущие направления;
- `/catalog/` и `/product/?model=...` — прежние страницы YTO.

После загрузки сохраните «Настройки → Постоянные ссылки» и очистите кэш WordPress/браузера. Маршруты рассчитаны на WordPress в корне домена.

## Замена фотографий, баннера и иконок

Все изображения Sampo задаются в `sampo-data.json`, без редактирования шаблонов:

- общее поле `banner` — баннер главной и каталога. Загрузите, например, `images/sampo-banner.webp` и укажите этот путь вместо `assets/images/sampo/banner.svg`;
- у каждой модели поле `image` — собственное фото. Например, `images/sampo-c12.webp`. Это фото используется в карточке и на странице модели;
- текст и параметры находятся рядом в JSON. Сохраняйте корректный JSON, без комментариев и лишних запятых.

Пути относительны папке темы. Шаблоны добавляют `get_template_directory_uri()` автоматически.

Иконки категорий: `assets/images/categories/tractor.svg`, `combine.svg`, `tillage.svg`, `wheel.svg`. Это одноцветные SVG, окрашиваемые CSS в серый/красный. Для других форматов поменяйте имя файла в массиве `equipment-navigation.php`.

## Проверки

Пройдены PHP-проверки синтаксиса и Playwright-проверки Sampo: четыре модели, документы, фильтры/поиск/сортировка, сравнение, неизвестные модели с HTTP 404, переходы YTO/Sampo, активные категории, WhatsApp/UTM, отсутствие телефона в аналитике, работа без JavaScript и ширины 320/390/768/1440 px. Предпросмотр использует минимальные WordPress-заглушки, а не установленную тему на вашем сервере.

Для запуска локально: `php -S 127.0.0.1:8012 tests/preview-router.php`, затем `ATM_PREVIEW_URL=http://127.0.0.1:8012 node tests/sampo-smoke.cjs`. Нужен Playwright с Chromium `/usr/bin/chromium`. Существующие проверки YTO/филиалов также принимают `ATM_PREVIEW_URL`; фото YTO, отсутствующие в репозитории и добавляемые владельцем на хостинге, в тесте каталога заменяются только тестовым изображением.
