# Farmet — установка и состав обновления

Ветка `farmet` создана из актуальной `sampo`, коммит `3d2718d`. Последние изменения владельца в YTO/Sampo сохранены. На хостинг файлы автоматически не загружаются.

## Что сделано

- Отдельные главная Farmet, каталог и один шаблон товара для всех моделей. Общие размеры контейнера, баннеров, кнопок и блоков АТМ/YTO; зелёный логотип Farmet и красные акценты АТМ.
- 14 позиций из предоставленной таблицы, включая три демо-позиции. Раздельные фильтры назначения, рабочей ширины и демо, поиск, сортировка и сравнение до трёх моделей.
- Карточки с шириной, глубиной, требуемой мощностью **трактора**, рабочими органами и сцепкой. Ширина Falcon 6 Compact, ширина Micro-Drill 800 и их требования к мощности не выведены из названия: этих параметров в таблице нет.
- Демо-позиция не выдаётся за подтверждённое наличие: состояние, наработка и комплектация требуют уточнения.
- Страница товара содержит WhatsApp с моделью, телефон, форму, характеристики, ответы по совместимости/гарантии/финансированию и три другие позиции Farmet.
- Общая категория «Почвообрабатывающая техника» на главных YTO/Sampo/Farmet теперь ведёт в `/farmet/`; на главной Farmet выделена красным. В каталогах и товарах полосы категорий нет.
- Информация о Farmet из презентации: производство в Ческа Скалица, Чехия; материалы eXtra STEEL; ISO 9001:2015. Указанная в презентации трёхлетняя гарантия описана с оговоркой о применимости и условиях договора, особенно для демо-машин.
- Из PDF извлечены неизменённые изображения: завод и три иллюстрации техники в поле. Они использованы в разделе о производителе, но не присвоены конкретным моделям без подтверждения.
- Презентация доступна для скачивания. Финансирование — консультация без придуманных ставок, субсидий и цен. Параметры лизинга C12 из Sampo не перенесены на Farmet.
- Формы подготавливают WhatsApp-сообщение; посетитель отправляет его самостоятельно. Серверной базы заявок этим обновлением не создаётся. Сохраняются UTM текущей вкладки, события `atm_form_prepared` / `atm_contact_click` получают `brand: farmet`, контекст формы и валидный код модели. Имя, телефон и текст обращения в события не попадают. Счётчики Google/Meta не подключаются автоматически.

## Какие файлы загрузить

Сделайте резервную копию темы. Архив обновления распакуйте **в папку активной темы**, не в корень WordPress и не как новую тему. Не удаляйте существующую тему, фотографии, `functions.php` и конфигурацию WordPress. Если после последнего GitHub-обновления вы меняли CSS на хостинге, сначала объедините свои изменения.

Новые файлы:

- `farmet.php`, `farmet-catalog.php`, `farmet-product.php`;
- `farmet-functions.php`, `farmet-data.json`, `farmet.js`;
- папка `assets/images/farmet/`;
- `assets/docs/farmet-presentation.pdf`.

Обновлённые: `equipment-navigation.php`, `marketing.js`, `style.css`; ссылки на версии CSS/JS обновлены в `front-page.php`, `catalog.php`, `product.php`, `sampo.php`, `sampo-catalog.php`, `sampo-product.php`. Они включены в архив. `index.html` не нужен для WordPress.

Используются существующие `site-data.php`, `pages.js`, иконки `assets/images/categories/`, локальная библиотека `assets/vendor/lucide-0.468.0.min.js`, нейтральная заглушка `assets/images/sampo/banner.svg`. Они включены в архив как зависимости. Существующие файлы YTO/Sampo, которых нет в архиве, оставьте на месте.

## Создать страницы WordPress

| Название | Ярлык | Шаблон |
|---|---|---|
| Farmet | `farmet` | **Farmet — главная** |
| Каталог Farmet | `farmet-catalog` | **Farmet — каталог** |
| Техника Farmet | `farmet-product` | **Farmet — товар** |

Страницы опубликуйте без родительской страницы. Главная сайта остаётся YTO. Товар создаётся **одной страницей**: например, `/farmet-product/?model=SOFTER-6PS`. На каждый товар отдельная WordPress-страница не нужна.

Сохраните «Настройки → Постоянные ссылки», очистите кэш сайта и браузера. Ссылки рассчитаны на WordPress в корне домена.

## Как заменить баннеры и фотографии

В `farmet-data.json` отдельные параметры:

- `banner`: сейчас `images/hero.webp` — главный баннер YTO, используется также в шапке каталога;
- `financeBanner`: `images/banner1.webp` — фон блока финансирования;
- `contactBanner`: `images/banner2.webp` — фон формы;
- `aboutImage`: `assets/images/farmet/factory.png` — завод из презентации;
- поле `image` у каждой модели — фото конкретного товара. Сейчас стоят тематические SVG-заглушки.

Например, загрузите `images/farmet/softer-6ps.webp` и укажите этот путь у Softer 6PS. Шаблон автоматически добавит `get_template_directory_uri()`. Сохраняйте корректный JSON без комментариев и лишних запятых. Баннеры можно заменить собственными путями Farmet независимо от YTO.

Модели с одинаковым типом сейчас используют общую заглушку. Для индивидуальных фото достаточно изменить `image` у нужного товара. Иллюстрации в блоке «Farmet в работе» — общие материалы производителя, а не фото всех 14 продаваемых комплектаций.

## Источники и ограничения

1. Таблица моделей из сообщения владельца: модельные характеристики и отметки демо. Подробная фиксация — [FARMET-SOURCES.md](FARMET-SOURCES.md).
2. Загруженная **«Презентация Farmet AGM - Farmet.pdf»**, 5 страниц: информация о производителе и иллюстрации. Исходный адрес, напечатанный в PDF: `https://www.farmet.cz/ru/farmet-agm-presentation`.
3. Адрес официального каталога, предоставленный владельцем, сохранён как ссылка на раздел производителя. В данной среде прямые запросы к сайту и хранилищу фотографий блокируются HTTP 403, поэтому актуальность страниц отдельных товаров и их параметры не подтверждались. Адреса конкретных страниц производителя не выдумывались.
4. Неоднозначное обозначение материала Cambridge CV9 + SC9 не расшифровано предположением: материал запрашивается по спецификации. У Cambridge требование к трактору — **от 125 л.с.**, без придуманного верхнего предела.
5. Модели, цены, ставки, статистика сотрудников/клиентов и заявленный статус дилера из референса дизайна не переносились без источника.

## Проверено

PHP lint; тесты Farmet, YTO и Sampo в Chromium. Все 14 страниц товаров, 404 для неизвестных моделей и массивов в query, поиск/фильтры/сортировка/сравнение, формы/UTM/события без персональных данных, PDF, реальные изображения из презентации, работа каталога и параметров без JavaScript; ширины 320/390/768/1440 px.

Это локальный PHP-предпросмотр с минимальными WordPress-заглушками, не проверка установленного сайта на хостинге. Фото YTO/Sampo, управляемые владельцем и отсутствующие в репозитории, не входят в архив Farmet.

Для локальной проверки: `php -S 127.0.0.1:8014 tests/preview-router.php`, затем `ATM_PREVIEW_URL=http://127.0.0.1:8014 node tests/farmet-smoke.cjs`. Нужны Playwright и Chromium `/usr/bin/chromium`.
