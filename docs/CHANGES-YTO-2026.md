# Обновление сайта АТМ по каталогу YTO от 15.10.2026

## Источник и границы проверки

Использована загруженная часть **«YTO каталог Б (П) последний 15.10.26-16-32.pdf»**, 17 страниц. Технические таблицы — страницы 22–31 оригинальной нумерации. Текстовые страницы были изображениями: значения сверены визуально с таблицами, OCR использовался как вспомогательный инструмент.

Часть **1–15** всё ещё превышает лимит переноса файла 32 МБ и не прочитана. Из неё не переносились история компании, дополнительные преимущества или коммерческие условия. Для продолжения этой части отправьте отдельные файлы 1–7 и 8–15, каждый до 32 МБ.

## Что изменено

### Каталог и данные

- Вместо шести демонстрационных моделей — десять моделей из технических таблиц.
- Один исполняемый источник данных **`catalog-data.js`** для каталога, главной и карточки продукта; больше нет отдельных наборов цен и мощности в HTML и JS.
- Старые демонстрационные X804 и X1204 удалены из текущего списка. Они не перенаправляются автоматически на другие реальные модели.
- Добавлены двигатели, объём, мощность и обороты; передаточные числа, скорости, сцепление и тормоза; ВОМ, гидровыходы и навеска; масса, шины, база, клиренс, габариты, бак, аккумулятор, противовесы, кондиционер и ЗИП — только где параметр присутствует в таблице.
- Поиск по модели, фильтры по диапазону мощности и кондиционеру, сортировка по мощности и названию. Убрана бессмысленная сортировка по неподтверждённым ценам.
- Сравнение 2–3 моделей в отдельном окне: двигатель, мощность, гидравлика, бак, масса, кондиционер и передачи.
- PDF доступен по ссылке с честным обозначением части 16–32. На странице модели ссылка открывает её конкретную таблицу.

### Страница продукта

- Название, описание, характеристики, фото и ссылки WhatsApp подставляются для выбранной модели.
- Характеристики разделены на четыре раскрываемых блока.
- Похожие модели выбираются по близкой мощности, текущая модель исключается.
- Несуществующая модель показывает сообщение и переход в каталог, вместо скрытой подмены на X804.
- Заявка в WhatsApp содержит название выбранного трактора.
- Галерея строится по списку фото; при одном изображении пустые/повторяющиеся миниатюры скрыты.

## Файлы и установка в WordPress

1. Сохраните резервную копию текущей темы и своих изображений.
2. Загрузите в **активную тему** `catalog.php`, `product.php`, `front-page.php`, `style.css`, `pages.js`, `script.js`, `catalog-data.js`, `catalog-ui.js`.
3. Добавьте содержимое `assets`, объединяя папки. Не удаляйте свои картинки или другие файлы темы.
4. `front-page.php` — готовая главная; WordPress использует этот файл для главной страницы автоматически. `index.html` сохранён как исходная версия той же разметки; обычный веб-сервер не выполнит PHP внутри HTML-файла.
5. У страниц «Каталог» и «Продукт» оставьте выбранные шаблоны и адреса `/catalog/` и `/product/`. Дополнительные страницы товаров создавать не нужно. Если адреса другие, измените их в `catalog-ui.js` и ссылках шаблонов.
6. Очистите кеш сайта/плагина/CDN и браузера. Основные CSS/JS подключены с версией `yto-20261018`.
7. Проверьте наличие, цены, условия покупки и спорные данные источника у менеджера перед публикацией коммерческого предложения.

`docs` и `tests` на хостинг загружать не обязательно. `ekzomassage` не менялся и к каталогу YTO не относится. Данные и код ранее созданной выставочной формы этим обновлением не затрагиваются.

## Как заменить фотографии

Сейчас у каждой модели нейтральная SVG-заглушка с её названием. Например, NMF804-8:

```
assets/images/models/nmf804-8.svg
```

Для фотографии:

1. Добавьте `assets/images/models/nmf804-8.webp` (или JPG/PNG).
2. В `catalog-data.js` у объекта с `id: "NMF804-8"` измените `image` на `assets/images/models/nmf804-8.webp`.
3. Для дополнительных ракурсов заполните `gallery`, например:

```js
"gallery": [
  "assets/images/models/nmf804-8-side.webp",
  "assets/images/models/nmf804-8-cabin.webp"
]
```

Путь в одном объекте обновит изображение сразу в каталоге, главной и странице продукта. Не подставляйте фото другой модели. Фоновую графику главной заменяйте по существующим путям в её разметке.

## Проверки

- PHP-lint шаблонов на PHP 8.4.
- Локальное выполнение PHP-шаблонов через `tests/preview-router.php`; это предварительный просмотр с минимальными функциями WordPress, а не полноценная установленная WordPress-среда.
- Браузер Chromium: все десять моделей, фильтры, сортировка, лимит сравнения, таблица сравнения, WhatsApp, неизвестный ID, меню, PDF и отсутствие горизонтального переполнения при ширине 320/390 px.
- Технические значения сверены с изображениями предоставленных таблиц. Информация из недоступных страниц 1–15 не выдаётся за проверенную.

Запуск проверки в среде с PHP и Playwright:

```bash
php -S 127.0.0.1:8010 -t . tests/preview-router.php
node tests/catalog-smoke.cjs
```

Доступа к файловому менеджеру хостинга нет: публикация в GitHub и фактическое обновление сайта на хостинге — отдельные действия.
