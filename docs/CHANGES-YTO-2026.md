## Файлы и установка в WordPress

1. Сохраните резервную копию текущей темы и своих изображений.
2. Загрузите в **активную тему** `catalog.php`, `product.php`, `front-page.php`, `style.css`, `pages.js`, `script.js`, `catalog-data.js`, `catalog-ui.js`.
3. Добавьте содержимое `assets`, объединяя папки. Не удаляйте свои картинки или другие файлы темы.
4. `front-page.php` — готовая главная; WordPress использует этот файл для главной страницы автоматически. `index.html` сохранён как исходная версия той же разметки; обычный веб-сервер не выполнит PHP внутри HTML-файла.
5. У страниц «Каталог» и «Продукт» оставьте выбранные шаблоны и адреса `/catalog/` и `/product/`. Дополнительные страницы товаров создавать не нужно. Если адреса другие, измените их в `catalog-ui.js` и ссылках шаблонов.
6. Очистите кеш сайта/плагина/CDN и браузера. Основные CSS/JS подключены с версией `yto-20261018`.
7. Проверьте наличие, цены, условия покупки и спорные данные источника у менеджера перед публикацией коммерческого предложения.

`docs` и `tests` на хостинг загружать не обязательно. `ekzomassage` не менялся и к каталогу YTO не относится. Данные и код ранее созданной выставочной формы этим обновлением не затрагиваются.

## Как заменить фотографии

Сейчас у каждой модели нейтральная SVG-заглушка с её названием. Например, NMF804-8:

```
assets/images/models/nmf804-8.svg
```

Для фотографии:

1. Добавьте `assets/images/models/nmf804-8.webp` (или JPG/PNG).
2. В `catalog-data.js` у объекта с `id: "NMF804-8"` измените `image` на `assets/images/models/nmf804-8.webp`.
3. Для дополнительных ракурсов заполните `gallery`, например:

```js
"gallery": [
  "assets/images/models/nmf804-8-side.webp",
  "assets/images/models/nmf804-8-cabin.webp"
]
```

Путь в одном объекте обновит изображение сразу в каталоге, главной и странице продукта. Не подставляйте фото другой модели. Фоновую графику главной заменяйте по существующим путям в её разметке.

## Как установить итоговое обновление

1. Сделайте резервную копию темы и базы WordPress. Скопируйте файлы этого обновления в активную тему, сохранив свои фотографии и существующие `functions.php`/`style.css` заголовки темы при ручном объединении.
2. Обновите `catalog-data.js`, `catalog-ui.js`, `pages.js`, `script.js`, `style.css`, `front-page.php`, `catalog.php`, `product.php`; добавьте `site-data.php`, `marketing.js`, `branches-data.json`, `branches.js`, `branches.php`, `service.php`, `privacy.php`, PDF и изображения-заглушки из `assets`.
3. Создайте и опубликуйте страницы WordPress: «Филиалы» со slug `branches` и шаблоном «Филиалы АТМ»; «Сервис» со slug `service` и шаблоном «Сервис YTO»; «Конфиденциальность» со slug `privacy` и шаблоном «Конфиденциальность АТМ». Каталог — slug `catalog`, товар — slug `product`, с соответствующими шаблонами. Товар создаётся одной страницей, модели выбираются через `?model=...`.
4. Сохраните постоянные ссылки WordPress и очистите кэш. Сайт предполагает WordPress в корне домена. Откройте каталог, товар, филиалы и сервис с телефона.
5. Фото заменяйте по путям в `catalog-data.js`; баннеры главной — `images/hero.webp`, `images/banner.webp`, `images/banner2.webp` согласно разметке темы. Архив не содержит ваших новых фото.
6. Для рекламы создайте цели по событиям выше через вашу систему тегов. Форму подготовки сообщения не называйте подтверждённой заявкой. Кампании можно вести на `/catalog/`, `/product/?model=NMF804-8`, `/branches/?city=aktobe`, `/service/` с UTM-метками.

Проверено локально с PHP 8.4 и Chromium: существующий smoke-тест каталога, поиск филиалов, UTM и события, сервисная форма, страницы шириной 320/390/1440. Это предпросмотр шаблонов с минимальными WordPress-заглушками, не проверка вашей установленной темы на хостинге.
