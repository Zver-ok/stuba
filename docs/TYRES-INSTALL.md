# Шины — установка и обновление АТМ

Ветка `tyres` создана из актуальной `farmet`, коммит `bb3bf74`. Сохранены последние изменения владельца: пути фотографий Farmet, изменения шаблонов/стилей и новые характеристики C24 в Sampo. На хостинг обновление автоматически не загружалось.

## Состав раздела

- Главная шин по предоставленному образцу: баннер с шинами, два бренда, подбор по размеру / бренду / технике, карточки с ценами, помощь с подбором, преимущества, форма и футер.
- В каталог перенесены **только 25 позиций** из `Тех характеристики(1).xlsx`: 13 TRONMAX и 12 ARMOUR. Сторонние бренды из референса не добавлены.
- Цены перенесены точно, от 40 000 до 750 000 ₸. На карточках показана конкретная цена по прайсу, без придуманного «от». Актуальную цену, наличие и комплектность подтверждает менеджер; статус «в наличии» и бессрочная гарантия не выдуманы.
- Отдельный каталог с поиском, фильтрами размера, бренда, профиля, диаметра, типа по прайсу, применения, сезона, комплектности и модели/рисунка. Сортировка по цене и диаметру, сравнение 2–3 позиций. Фильтры можно передать в URL.
- Товар: цена, оригинальные технические строки Excel, заявка с количеством, WhatsApp, телефон, ответы по подбору и три другие позиции из этого же прайса.
- Тип «КГШ» сохранён без неподтверждённого преобразования в «диагональная». Радиальные исполнения имеют индексы нагрузки/скорости, указанные в файле. Профиль у размера вида `8,3-20` не выдуман. В фильтре для таких позиций есть «Не указан».
- Позиции одного размера с разной слойностью различаются кодом товара: например, ARMOUR 17,5-25/16 и 17,5-25/24.
- Общая категория «Колеса» на главных YTO/Sampo/Farmet ведёт в `/tyres/`. На самой главной шин после баннера показаны бренды, как в референсе. В каталоге и товаре дополнительных полос категорий нет.
- События `atm_tyres_selection`, `atm_form_prepared`, `atm_contact_click` получают контекст `tyres`; имя, телефон и описание задачи в аналитику не передаются. UTM текущей вкладки включаются в подготовленное WhatsApp-сообщение.
- При отключённом JavaScript отправка новой формы заблокирована; доступны телефон и прямая ссылка WhatsApp, чтобы контакты не попадали в URL при стандартной отправке браузером.
- Формы только подготавливают сообщение: посетитель сам отправляет его в WhatsApp. База заказов, оплата, корзина, реальный остаток и рекламные пиксели не устанавливаются этим обновлением.

## Изображения

В Excel нет фотографий. Для дизайна созданы **иллюстрации**: общий баннер с шинами и два обобщённых изображения протектора — сельскохозяйственный и индустриальный. Это не фотографии конкретных TRONMAX или ARMOUR; на карточках/страницах есть соответствующее пояснение. Изображения не снабжены поддельными логотипами или маркировкой моделей.

Бренды в полосе представлены надписями TRONMAX и ARMOUR. Логотипы других брендов из референса не добавлялись. В исходниках есть также запасные схематичные SVG.

Все пути в `tyres-data.json`:

- `banner` — `assets/images/tyres/hero.png`, главный баннер и шапка каталога;
- `selectionBanner` — фон секции подбора;
- `supportBanner` — `images/banner1.webp`, фон блока консультации из YTO;
- `contactBanner` — `images/banner2.webp`, фон формы из YTO;
- `image` каждой позиции — своё фото товара. Пока используется общая иллюстрация по типу применения.

Для отдельного фото загрузите, например, `images/tyres/tronmax-8-3-20.webp` и укажите этот путь в `image` нужной позиции. Шаблоны добавят `get_template_directory_uri()` автоматически. Изменение фото одной модели не требует создавать новую страницу. Сохраняйте корректный JSON.

## Установка в WordPress

1. Сделайте резервную копию действующей темы. Не удаляйте тему целиком, `functions.php`, пользовательские фотографии и конфигурацию WordPress. Если правки на хостинге новее GitHub, объедините их перед заменой.
2. Распакуйте архив обновления **в активную тему**, например `wp-content/themes/atm/`, сохраняя папки.
3. Создайте и опубликуйте три страницы **без родительской страницы**:

| Название | Ярлык (slug) | Шаблон |
|---|---|---|
| Шины | `tyres` | **Шины — главная** |
| Каталог шин | `tyres-catalog` | **Шины — каталог** |
| Товар — шины | `tyres-product` | **Шины — товар** |

4. Страница товара нужна **одна для всех 25 позиций**. Ссылки автоматически имеют вид `/tyres-product/?model=TRONMAX-R-1-8-3-20-6PR`. Сохраняйте коды `id`, если уже используете ссылки в рекламе.
5. Главная сайта остаётся YTO. Сохраните «Настройки → Постоянные ссылки», очистите кэш WordPress и браузера. Сайт рассчитан на WordPress в корне домена.

Новые файлы: `tyres.php`, `tyres-catalog.php`, `tyres-product.php`, `tyres-functions.php`, `tyres-data.json`, `tyres.js`, `assets/images/tyres/`, `assets/docs/tyres-specifications.xlsx`.

Обновлены `equipment-navigation.php`, `marketing.js`, общий `style.css` и версии CSS/JS в шаблонах YTO/Sampo/Farmet. Все изменённые PHP-шаблоны включены в архив. Общие `site-data.php`, `pages.js`, иконки и локальная библиотека Lucide остаются необходимыми зависимостями; архив содержит их копии. `index.html` для WordPress не нужен.

## Источник цен и параметров

Исходный Excel содержит один лист «Каталог шин», 25 товарных блоков. Значения каждой строки и цены сверены автоматически с ячейками Excel. Исходные названия и размеры сохранены, включая запятые и нулевые дробные знаки (`14,00-24`, `6,50-10`). Числовые значения в фильтрах нормализованы отдельно для удобного поиска.

Производные поля ширины, профиля и диаметра разбираются из маркировки размера. Для метрических значений ширина показывается в мм, для дюймовых — в дюймах. Неуказанный профиль остаётся пустым. Совместимость с диском, допустимая нагрузка и пригодность для конкретной машины требуют проверки специалистом.

Дата действия прайса, наличие, НДС, стоимость доставки и исчерпывающие условия гарантии не указаны, поэтому не утверждаются. Цены не являются автоматическим подтверждением заказа.

## Проверки

- `python tests/verify-tyres-source.py` — независимая проверка всех 25 названий, цен и строк характеристик по Excel; нужен `openpyxl`.
- PHP lint для новых шаблонов и помощника, синтаксис JavaScript.
- Playwright: три вкладки подбора, применение параметров через URL, поиск, фильтры, сортировка, сравнение до трёх шин, все 25 страниц товаров, раздельные комплектации, количество в WhatsApp, UTM без дублирования, события без имени/телефона, 404 для неверных моделей, каталог и параметры без JavaScript.
- Ширины 320/390/768/1440 px, мобильное меню, загрузка изображений и исходного XLSX.
- Дополнительно проверены сценарии YTO/Sampo/Farmet. Регрессионные тесты приведены к последним изменениям владельца: добавленным характеристикам C24 и фотографиям Farmet, хранящимся на хостинге. Отсутствующие в репозитории фото Farmet в тесте заменяются только локальной тестовой картинкой; сами пути фото в данных не менялись.

Локальный запуск: `php -S 127.0.0.1:8015 tests/preview-router.php`, затем `ATM_PREVIEW_URL=http://127.0.0.1:8015 node tests/tyres-smoke.cjs`. Нужны Playwright и Chromium `/usr/bin/chromium`. Это предпросмотр с WordPress-заглушками, не проверка установленной темы на вашем сервере.
